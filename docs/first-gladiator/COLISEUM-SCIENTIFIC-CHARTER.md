# Coliseum Scientific Charter

*One page. Operational rules that keep theory from outrunning evidence. Distilled from the frozen study guide (`Claude-Wiki/03_wiki/projects/coliseum/CONSTITUTIONAL-SOUL-TRACK-HYPOTHESES.md`); adds no new theory. Binding on all trajectory-science tracks.*

## 1. Order of operations (never run it backwards)

```
trace → reproducible structure → intervention → held-out prediction → provisional interpretation
```

Philosophy enters at exactly three points: (a) to generate rival hypotheses, (b) to expose assumptions hidden in the schema, (c) to interpret results **after** controls survive. Philosophy never fixes the latent structure in advance. If a document reaches "provisional interpretation" without a completed run behind it, it is theory, not evidence — file it, freeze it, do not act on it.

## 2. Admission gates (a track must be able to fail cheaply)

Every ambitious track names **one cheap experiment whose null blocks the rest**, before any expansion. The gate must be *allowed to close*: a null result is a successful outcome, not a failure to be negotiated away by adding richer agents, longer stories, or more interpretive metrics. `Value(test) ≈ (future work invalidated if null) / (cost of test)` — prefer the ugliest minimum test with the highest ratio.

- **Constitutional Soul Track gate:** does changing the ORDER of an identical experience set produce a reproducible difference in a predefined terminal behavior, under preregistered controls, with the instrument calibration-validated first? (`m7-scrambled-history-gate`.) Until it passes, these stay blocked: durable developmental trajectory, identity-critical events, constitutional transitions, Platonic regime descent, thumos-as-primitive, recovery/hysteresis, city-soul isomorphism.

## 3. Claim ladder (do not skip a rung)

The machine states in `configs/registry/claims.yaml` are the only load-bearing rungs:

```
observation → replicated → accepted
```

Annotations above/below the machine states — **vision → hypothesis** (above `observation`) and **mechanistic → general → philosophical** (above `accepted`) — are narrative only and never register as claims. A result enters at `observation`; it does not climb without passing the prior rung (replication across paraphrases/seeds/models before `replicated`; independent audit + council acceptance before `accepted`). No philosophical language in a primary result statement.

## 4. Theory-to-evidence budget

**No more than one major theory artifact before one empirical gate.** For every substantial new theory page, require one of: a preregistered test, a completed run, a control, a failed hypothesis, or a replication. Theory and evidence must alternate. When a theory is sufficient to design a discriminating test (a stateable null, a rival explanation, a controlled difference, and a result that would shrink or kill the idea), **freeze it** — further refinement then has lower expected value than the first measurement.

## 5. Preregistration (freeze before the run)

Before any run, freeze: the null, the exact conditions and orderings, the model/decoding regime, the terminal probe, the metrics, exclusion rules, sample identity, stopping conditions, and interpretation limits. Write the result statement in blank form beforehand: *"Under regime ___, ordering ___ produced outcome ___ vs ordering ___; estimated effect ___ under metric ___; this does/does not pass the predefined threshold."* Rival models are named explicitly (no-history, recency, event-set, ordered-history, narrative-prior) so the run discriminates, not merely rejects a null.

## 6. The Council's scientific-audit mandate

The auditor checks more than code. It audits whether the experiment **isolates the intended variable**: does the schema embed the desired conclusion; are control conditions semantically matched; were metrics frozen before observation; do the claims stay inside the evidence. The auditor is empowered to rule: **"the implementation is correct, but the experiment does not identify the claimed cause."** That verdict blocks promotion exactly like a code defect.

## 7. Measure-never-reward (inviolable)

No moral-index scalar; decomposed rates only. Never feed a derived label, metric, or aggregator output back into an agent's decision, a scenario's parameters, or a reward. Apparent value conflicts stay visible as a vector unless evidence and explicit argument justify combining them. A decider or scenario tuned from a run's own output is a rigged instrument, not a measurement.

---

*Falsification is progress. The Coliseum becomes a real instrument when it can destroy its builder's favorite theory — reward the eliminated explanation, the discovered confound, the narrower claim, the closed gate.*
